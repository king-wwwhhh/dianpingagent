# 惠生活秒杀接口压测报告

> 测试时间：2026-09-12 ｜ 环境：本机（Windows，应用与 MySQL/Redis/Kafka 同机）

## 一、测试环境与参数

| 项目 | 值 |
|---|---|
| 被测接口 | `POST /voucher-order/seckill/{id}`（券 id=15，秒杀窗口内） |
| 应用 | local-life（Spring Boot 2.3.12，内嵌 Tomcat，8081） |
| 压测工具 | JMeter 5.6.3（CLI 模式） |
| 并发模型 | 200 线程，10s ramp-up，持续 30s，循环取 `tokens.csv`（1205 个独立登录用户） |
| 初始库存 | 1000（`tb_flash_coupon.stock`，Lua 资格判断用 Redis `flash:stock:15`） |
| 基础设施 | MySQL 8（本机 3306）、Redis 7（Docker 6379）、Kafka 3.7（Docker 9092，bitnami 单机） |
| 链路 | Lua 原子资格判断 → Kafka（seckill-orders，1 分区）→ 消费者落库（Redisson 锁 + 查重 + 条件更新扣减） |

## 二、结果总览

| 指标 | 数值 |
|---|---|
| 总请求数 | **291,630**（30 秒） |
| 持续吞吐 | **≈ 9,693 请求/秒** |
| 平均响应时间 | **16 ms**（最小 1ms / 最大 99ms） |
| HTTP 200（成功获得资格 + 库存不足业务响应） | 1,205 |
| — 其中真正下单成功 | **1,000**（= 初始库存，全部经 Kafka 异步落库） |
| — 其中"库存不足"业务拒绝 | 205 |
| 其余请求 | 401（token 池耗尽后的无效登录态，压测模型限制，见第四节） |

## 三、核心正确性证据（面试最值钱的部分）

1. **防超卖：PASS** —— 1000 库存 → 1000 订单 → Redis `flash:stock:15 = 0`，DB `stock = 0`。**一笔未超卖**。
2. **一人一单：PASS** —— `COUNT(DISTINCT user_id) = COUNT(*) = 1000`，无重复订单。
3. **消息可靠性** —— 1000 个资格全部经 Kafka 消费落库，HTTP 入口秒回订单号，DB 订单数与 Redis 资格数一致（无丢单）。
4. **高并发下库存精确归零** —— 29 万请求冲击下，Lua 原子判断把有效请求精确限制在 1000。

## 四、数据解读口径（避免面试被绕进去）

- **9,693/s 是全链路持续吞吐**，其中大部分是"库存售罄后的拒绝流量"和"登录态失效的 401 流量"——这两类都走不到 DB，所以能跑得很高。
- **有效下单窗口**在前几秒：1205 个用户（200 并发、ramp 未爬满）约 5 秒内完成 1000 单资格判定，成功路径下单速率 **≈ 200-400 单/秒**，瓶颈在 Kafka 单分区串行消费 + MySQL 行锁扣减（这是单机单实例的预期瓶颈）。
- **401 占比高是测试模型限制**：一人一单 + token 一次性 → 1205 个 token 耗尽后线程仍持续打 401。不影响正确性结论；若要更"好看"的持续成功吞吐曲线，把 ramp-up 加长、线程数对齐 token 数即可。
- 本机压测（应用/MySQL/Redis/Kafka 同机）数值偏乐观，仅供相对比较与正确性验证，不代表生产容量。

## 五、复现方式

```bash
# 1. 数据准备（一人一单，需独立 token）
#    登录 1205 个用户（或向 Redis 批量写 login:token:<uuid> Hash：id/nickName/icon 字段）
# 2. 重置库存与订单
#    UPDATE tb_flash_coupon SET stock=1000 WHERE voucher_id=15;
#    DELETE FROM tb_coupon_order WHERE voucher_id=15;
#    redis-cli DEL flash:stock:15 flash:order:15
# 3. 压测
cd heima-dianping/jmeter
jmeter -n -t seckill-test.jmx -Jthreads=200 -Jrampup=10 -Jduration=30 \
  -JvoucherId=15 -Jhost=127.0.0.1 -Jport=8081 \
  -l results/seckill.jtl -e -o results/report
```

HTML 报告：`heima-dianping/jmeter/results/report/index.html`
原始数据：`heima-dianping/jmeter/results/seckill.jtl`
